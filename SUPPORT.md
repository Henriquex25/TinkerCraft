# Support

TinkerCraft is an early-stage, community-maintained PHP / Laravel desktop tool. Support and fixes are best effort; there is no response-time commitment.

- Use [Help and Questions](https://github.com/Henriquex25/TinkerCraft/discussions/categories/help-and-questions) for setup and usage questions.
- Use [Ideas](https://github.com/Henriquex25/TinkerCraft/discussions/categories/ideas) for open-ended proposals and feedback.
- Use the [bug report form](https://github.com/Henriquex25/TinkerCraft/issues/new/choose) for reproducible problems and the feature form for concrete requests.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Do not publish sensitive findings in an issue or discussion.

Include the app version, Linux distribution, PHP / Laravel version, connection type, and a small disposable reproduction where relevant. Redact credentials, SSH hosts, private paths, code, and query results from logs and screenshots. TinkerCraft runs real PHP with the selected user's permissions; use test data when reproducing execution problems.

Before contributing code, read [CONTRIBUTING.md](CONTRIBUTING.md). Larger changes benefit from a discussion before implementation. A request does not commit the maintainer to a delivery date.
