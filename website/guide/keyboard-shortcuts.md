# Keyboard shortcuts

Open the command palette with **Ctrl+Shift+P** or **F1**, search for an action, and press Enter. It includes contextual actions without an assigned shortcut.

These are the Linux defaults. Remap them under **Preferences → Keyboard shortcuts**, or open that section with **Ctrl+Alt+K**.

## Context matters

Inside a connection form, **Ctrl+Enter** tests the connection. Inside the updates dialog it starts the update. In forms, **Ctrl+S** saves the form.

Use Tab and Shift+Tab to move between controls, Enter/Space to activate them, and Escape to close a dialog. In Monaco, Tab normally indents; **Ctrl+M** switches Tab focus navigation so you can leave the editor with the keyboard.

A focused result-tree item uses Up/Down to navigate and Left/Right to collapse or expand. A focused editor/output divider accepts Left/Right to resize the panes.

Hover over an icon-only button to see its action and configured shortcut. The palette and Preferences are the complete reference for the commands available in your current context.
