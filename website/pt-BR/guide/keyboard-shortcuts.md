# Atalhos de teclado

Abra a paleta com **Ctrl+Shift+P** ou **F1**, busque uma ação e pressione Enter. Ela inclui ações do contexto atual sem combinação atribuída.

Estes são os padrões no Linux. Remapeie em **Preferências → Atalhos de teclado**, ou abra essa seção com **Ctrl+Alt+K**.

| Ação                                | Atalho padrão                        |
| ----------------------------------- | ------------------------------------ |
| Executar ou cancelar                | Ctrl+Enter / Ctrl+R                  |
| Formatar PHP                        | Alt+Shift+F                          |
| Salvar abas abertas                 | Ctrl+S                               |
| Exportar aba como PHP               | Ctrl+Shift+S                         |
| Abrir arquivo PHP                   | Ctrl+O                               |
| Nova aba / fechar aba               | Ctrl+N / Ctrl+W                      |
| Renomear aba                        | F2                                   |
| Próxima aba / aba anterior          | Ctrl+Tab / Ctrl+Shift+Tab            |
| Projetos e conexões                 | Ctrl+B                               |
| Nova conexão                        | Ctrl+Shift+N                         |
| Configurar conexão selecionada      | Ctrl+Alt+E                           |
| Selecionar conexão                  | Ctrl+Alt+P                           |
| Histórico                           | Ctrl+H                               |
| Preferências                        | Ctrl+,                               |
| Mostrar sugestões                   | Ctrl+Espaço                          |
| Atualizar autocomplete              | Ctrl+Alt+R                           |
| Diagnóstico do autocomplete         | Ctrl+Alt+I                           |
| Focar editor / saída                | Alt+1 / Alt+2                        |
| Ocultar ou mostrar saída            | Ctrl+J                               |
| Inspecionar / tabela / JSON         | Ctrl+Alt+1 / Ctrl+Alt+2 / Ctrl+Alt+3 |

## O contexto importa

No formulário de conexão, **Ctrl+Enter** testa a conexão. No diálogo de atualizações, inicia a atualização. Em formulários, **Ctrl+S** salva o formulário.

Use Tab e Shift+Tab para navegar entre controles, Enter/Espaço para ativá-los e Escape para fechar um diálogo. No Monaco, Tab normalmente indenta; **Ctrl+M** alterna a navegação de foco com Tab para sair do editor pelo teclado.

Na árvore, um item focado usa Cima/Baixo para navegar e Esquerda/Direita para recolher ou expandir. O divisor entre editor e saída aceita Esquerda/Direita quando focado.

Passe o mouse em um botão de ícone para ver a ação e o atalho configurado. A paleta e as Preferências são a referência completa das ações disponíveis no contexto atual.
